# witty

**DE** — PM-Awareness-Werkzeug: eine feste Methoden-Basis (14 Schritte
von Spark bis Snapshot), LLM-Facilitation und ein Hindsight-Audit, der
zeigt, welche PM-Methoden du längst anwendest — und wie sie heißen.
Benannt nach Wittgenstein: *"Die Grenzen meiner Sprache bedeuten die
Grenzen meiner Welt"* — man kann nur in die Richtungen bauen, für die
man die Sprache hat.

**EN** — A PM awareness tool: a fixed method base (14 steps from spark
to snapshot), LLM facilitation, and a hindsight audit that shows which
PM methods you already practice — and what they're called. Named after
Wittgenstein: *"The limits of my language mean the limits of my world"*
— you can only build in the directions you have language for.

## Status

## Prinzipien / Principles

- Klartext zuerst, Fachbegriff als Lern-Anker / plain language first,
  the textbook term as a learning anchor
- Methoden sind Optionen, nie Pflicht / methods are options, never
  mandatory
- Markdown bleibt Source of Truth / markdown stays the source of truth
- DE/EN von Anfang an / bilingual from day one
